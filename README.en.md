## 🛰️ PULSE — AI 实时观测站 (AI real-time observatory)

<p align="center">
  <img src="entries/2026-08-pulse-ai-observatory/screenshots/06-agent-deep-dive.png" width="720" alt="PULSE — AI real-time observatory">
</p>

A "24-hours-alive" tech radar: AI streams an interpretation of what's happening on Hacker News / GitHub **right now**, every visitor shares the same "current moment", rank-momentum badges track the movement, an agent autonomously picks 3 stories and deep-dives them with real fetched content, and a weekly tech report ships with one-click Markdown copy for team sharing.

**▶ Live preview**: [pulse — ai 实时观测站](https://d41c8754b3a14836980c67b0acfcddfa.prod.enterapp.pro/) (published on prod; loads the current shared snapshot, regenerates at most every 15 min)

Zero input. First fold is the content. Built in 7 bounded batches over 3 days, each batch independently verified from outside Enter — including direct database reads and OS-clipboard read-back.

## 🏮 Daily Verse (一日一诗) — AI poetry reading site

<p align="center">
  <img src="entries/2026-09-daily-verse-editorial-site/screenshots/01-desktop.png" width="720" alt="Daily Verse — AI poetry reading site">
</p>

The deliberate stylistic opposite of PULSE: rice-paper warm white, ink serif, cinnabar seals, vertical poem titles — an editorial/print aesthetic. One real classical Chinese poem per day with a three-part AI reading (faithful translation / imagery appreciation / one thought for today), shared by every visitor. Day-idempotent with no cron — at most one LLM call per day.

**▶ Live site**: [Daily Verse 一日一诗](https://92346ae03f4c440fb435995a5c68f861.prod.enterapp.pro/) (published on prod; loads today's card, generated by the day's first visitor UTC+8)

Zero input. Poem on first paint. The day-boundary behavior was witnessed in production: the first visitor after midnight triggered the next day's poem, and yesterday's card stayed archived. Honesty is in the contract: no dynasty field in the API means none shown, day one renders an honest empty archive, and the "one thought" section is explicitly labeled subjective.
