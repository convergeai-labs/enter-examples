# 配方复刻 · Recipes

> 🌐 **English** → 本页暂以中文为主,配方 prompt 本身为中文(目标平台为中文建站)。

把本陈列室的作品**复制到你自己的 Enter 账号**的最短路径。每个配方 = 一段可直接粘贴的 prompt + 你会碰到的 gate + 可调的旋钮。

## 怎么用(通用四步)

1. 打开 [Enter](https://enter.converge.ai),登录,新建对话
2. 把配方里的 prompt **整段粘贴**发送
3. 按提示过三道 gate:
   - **模型问答**——建站 agent 会问你关键选择(如内容生成用哪个模型),按推荐选即可
   - **Cloud(新建)**——确认创建云端实例(数据库 + 边缘函数)
   - **AI(启用/连接)**——为项目创建并连接一把 AI 密钥;弹窗里「新建」是 tab,真动作是「连接」
4. 构建完成后先**预览检查**,满意再自己点「发布」

> 配方里的 prompt 都是**建出线上真实站点的原文**(仅按复刻场景微调了发布护栏,改动处已注明)。

## 复刻公约

- 第一次构建**先别发布**:预览里确认内容真实、样式符合预期再发
- API key 只应存在于服务端;如果客户端代码里出现密钥,删掉让 agent 重做
- 配方产出的内容(诗词/新闻)都是公共领域或公开 API,但**你的站点你负责**
