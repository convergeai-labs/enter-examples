# 一日一诗 · Daily Verse — AI 诗词品读站

> 🌐 **English version** → [README.en.md](README.en.md)

**在线访问**:https://92346ae03f4c440fb435995a5c68f861.prod.enterapp.pro/(已发布 prod 正式地址)

一个编辑/出版美学的 AI 诗词品读站,完全在 [Enter](https://enter.converge.ai) 上构建——与这个系列里电子霓虹风的 PULSE 刻意对立,证明同一个 agent 工作流可以产出**完全不同气质**的网站。零输入,首屏即诗:每天一首真实诗词,AI 带你读,所有访客共享同一首「今日之诗」。

![桌面端整页](screenshots/01-desktop.png)

## 它能做什么

- **每日一诗,全访客共享**——今日诗签(诗题竖排、朝代·作者、诗文全文)首屏即达;每天(UTC+8)第一位访客触发生成,其后所有人读同一份
- **AI 三段式品读**——白话译意(忠实)/ 意象赏析(只基于诗文中的意象,不编造历史背景)/ 今日一读(一句当下联想,明确标注为主观随想)。不知道的背景就不说,宁可少写
- **按天幂等,不用 cron**——`day_key` 唯一约束保证一天只生成一首;并发触发由约束兜底,败方读胜出行;LLM 每天最多调用一次
- **真实诗源 + 诚实降级**——今日诗词公开 API 为主,内置 30 首公共领域诗词后备;API 不可达时自动切换并如实标注「外部 API 暂不可用」
- **复制诗签**——一键复制今日诗签的 Markdown 卡片(诗题/作者/诗文/一句品读摘录),可直接粘贴分享
- **往日诗签**——历史诗签时间线,点读任意一天,可返回今日

## 视觉规格(与 PULSE 反着来)

宣纸暖白 `#f7f3ea` / 墨色 `#2b2b2f` / 朱砂 `#c93b2e`;衬线字体优先(Noto Serif SC);诗题竖排 `writing-mode: vertical-rl`;纸纹纯 CSS 实现;印章式朱砂徽章;大量留白。禁止深色背景、霓虹、辉光、雷达/网格。1440×900 / 390×844 / 327×603 零横向溢出。

## 如何用 agent + skill 创作(指导叙事)

由 Claude Code 按 [enter-project-ops](https://github.com/convergeai-labs/enter-skills) skill 驱动 Enter 构建。分工:**Claude 规划与验证,Enter 执行。**

1. **风格反着写进契约**——本地 goal 文件先锁死视觉规格(色值/字体/禁令清单)与数据契约(按天幂等、诚实降级、禁止虚构),防止 agent 滑回默认的「AI 仪表盘风」。
2. **一个富创建 prompt**([prompts/00-creation.txt](prompts/00-creation.txt))——概念、视觉规格、数据源与降级、幂等模型、表结构 + RLS、页面结构、约束,一次说清。Enter 出计划,过模型问答(选了中文写作质感最佳的档)、Cloud、AI 三道 gate 后构建:边缘函数 + 唯一约束表 + 流式 UI。
3. **每环独立复验**——Enter 的回执是 claim。三档视口截图、console 审计、复制按钮用系统剪贴板(`pbpaste`)读回逐字比对,最强泳道是**用公开 anon key 直查数据库**:行内容、唯一约束、来源标注全部可数。
4. **跨天行为实测**——发布恰好临近零点:00:00:52(+8)首位访客自动触发次日新诗生成,昨日诗签保留为历史——按天幂等惰性刷新在生产环境真实走通,不是 claim。

### 诚实性(为什么可信)

- 诗源 API 不返回朝代字段:数据库如实存 `null`,页面只显示作者,不虚构朝代。
- 首日「往日诗签」如实显示空态(「暂无往日诗签——明日再来,便是第一篇」),不造假历史。
- AI 品读的「今日一读」段明确标注为主观随想,与译意、赏析分开。
